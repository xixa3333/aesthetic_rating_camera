# 影像美學評估系統 (Aesthetic Evaluation System)

本專案是一個基於深度學習的**影像美學評估（Aesthetic Quality Assessment, AQA）**系統。系統的核心目標是擺脫傳統「趨中、保守」的評分盲區，透過**分佈重塑、分層學習率與相對排序損失函數**，訓練出一個審美觀與人類高度一致、具備大膽給分能力的輕量化邊緣推論模型。

---

## 一、 系統核心架構

本系統採用現代軟體工程的**低耦合、高內聚**原則進行模組化設計，主要由以下四個核心模組組成：

```
                    ┌────────────────────────┐
                    │      config.yaml       │ (全局靜態配置)
                    └───────────┬────────────┘
                                │
┌─────────────────┐  標籤重塑   ▼   影像 Tensor  ┌─────────────────┐
│   dataset.py    ├─────────────────────────────►│    model.py     │
│ (資料與標籤前處理) │  (V型權重/Min-Max拉伸)        │ (MobileNetV3核心) │
└─────────────────┘                              └──────────┬──────┘
                                                            │ 輸出預測
                                                            ▼
┌─────────────────┐          控制訓練/驗證           ┌─────────────────┐
│    main.py      │◄─────────────────────────────►│   trainer.py    │
│ (全域依賴注入核)  │     (動態學習率/早停機制)       │ (訓練與早停控制引擎)│
└─────────────────┘                              └─────────────────┘

```

### 1. 資料與標籤重塑模組 (`dataset.py`, `transforms.py`)

* **職責**：負責影像的空間自適應補齊，以及對人類主觀投票數據（美學標籤）進行非線性重塑。
* **影像適配**：採用 `MeanPadToSquare` 演算法，計算影像邊緣平均色進行正方形填充，避免傳統強行縮放導致的構圖比例扭曲。

### 2. 骨幹網路 wrap 模組 (`model.py`)

* **職責**：以輕量化高效網路為視覺特徵提取大腦，並客製化後端回歸下游任務。
* **Backbone 選擇**：採用 `MobileNetV3-Large` 作為視覺特徵提取引擎，一方面利於未來在行動裝置（App）或邊緣設備上實現低延遲、免連網的即時硬體加速推論；另一方面，相較於從零訓練且缺乏全局視野的自製模型，MobileNetV3 具備在 ImageNet 百萬級數據上預訓練得到的通用特徵先驗，模型無需重新學習底層邊緣、光影與形狀，能更高效地遷移至主觀美學排序任務。

### 3. 執行與早停引擎 (`trainer.py`)

* **職責**：控制全域的反向傳播與驗證流程，負責調度優化器、動態學習率排程器（Scheduler），並根據指定的**相對排序指標**實施早停防禦。

### 4. 流程編排器 (`main.py`)

* **職責**：系統的「依賴注入核心」。負責解析靜態配置，實例化模型、損失函數、優化器，並將它們注入到 `Trainer` 當中，達成組件間的低耦合。

## 二、 核心演算法與資料流 (Pipeline)

系統的資料流從原始的「人類投票分佈」出發，經過前處理拉伸，進入神經網路進行「無邊界回歸」，最終端到端輸出美學分數。整體演算法流程如下：

```
[原始10維票數分佈] ──► [V型權重重要性重塑] ──► [重心計算] ──► [Min-Max邊界拉伸 (1-10分)]
                                                                     │
[終端評分輸出] ◄─── [torch.clamp 截斷防線] ◄─── [MobileNetV3+多樣本Dropout] ◄┘

```

### 流程拆解：

#### 步驟 1：標籤重要性重塑 (Distribution Reshaping)

真實世界的美學評分資料集（如 AVA）天生呈現高度聚攏的「鐘形常態分佈」（絕大多數照片都集中在平庸的 5 分左右）。為了賦予模型大膽給分的基因，系統在 `Dataset` 讀取階段執行非線性重塑：

1. 讀取 1 到 10 分的原始人類投票數。
2. 乘上一組預設的**逆頻率 V 型權重** $W = [22.5, 10.63, ..., 20.13]$，強行拉平分佈，放大兩極（極美與極醜）樣本的梯度影響力。
3. 對重塑後的機率分佈進行重新歸一化（Softmax 歸一化）。

#### 步驟 2：美學宇宙線性拉伸 (Target Scaling)

1. 計算重塑分佈後的加權期望值（即照片的期望重心分數）。
2. 依據資料集的真實期望極值（`min_score: 1.235` 至 `max_score: 9.497`），進行 Min-Max 線性映射：

$$Score_{scaled} = \frac{Score_{raw} - Score_{min}}{Score_{max} - Score_{min}} \times 9.0 + 1.0$$


3. 標籤在前處理即被撐開至 $1.0 \sim 10.0$ 的寬廣宇宙，使模型天生學會直接輸出大膽的分數。

#### 步驟 3：多樣本 Dropout 無邊界回歸 (Multi-Sample Dropout Inference)

1. 512x512 影像通過 `MobileNetV3-Large` 提取出高維度特徵。
2. 特徵穿過由 5 個不同隨機機率（$p=0.1 \sim 0.3$）組成的 **Multi-Sample Dropout 陣列**。
3. 穿過 5 組 Dropout 的特徵分別進入同一個 `nn.Linear(in_features, 1)` 線性層。
4. 對 5 組輸出取平均，得到無數學邊界鎖死的原始實數（Raw Score）。**模型內部不掛載 Sigmoid**，徹底根除兩端梯度消失的物理弊病。

#### 步驟 4：純粹推論端防線 (Boundary Clamping)

在實戰推論（`inference.py`）與測試端，模型直接輸出預測分數。為了防止無邊界線性層在外來極端噪點下噴出破表數值（如 11.5 分或 -0.5 分），在最終輸出端設置一道硬性**數值截斷（Clipping）防線**：


$$Score_{final} = \max(1.0, \min(10.0, Score_{raw}))$$


保證最終輸出絕對安全地鎖定在 $1.0 \sim 10.0$ 分之內。

## 三、 進階訓練與優化策略

為了讓輕量化的 MobileNetV3 衝破審美指標的天花板，系統實作了以下三項高階煉丹術：

### 1. 混合審美損失函數 (Hybrid Aesthetic Loss)

系統摒棄了單一距離優化的思維，手刻了混合損失函數：


$$\mathcal{L}_{total} = (1 - \alpha) \cdot \mathcal{L}_{Huber} + \alpha \cdot \mathcal{L}_{LCC}$$

* **$\mathcal{L}_{Huber}$（絕對誤差防線）**：在 $\delta=2.0$ 的設定下運行。在誤差大於 2.0 時自動切換為 L1 模式，避免極端異常樣本對模型產生毁灭性的梯度衝擊。
* **$\mathcal{L}_{LCC}$（相對排序信仰）**：將皮爾森相關係數（Linear Correlation Coefficient）映射為損失 $1.0 - r$。它不執著於絕對分數猜得準不準，而是瘋狂逼迫模型「把相對美醜順序排對」。
* **槓桿調和 ($\alpha = 0.7$)**：由於 LCC 的值域被嚴格封閉在 $[0, 2]$ 之間，而 Huber Loss 理論上無上限。因此將 $\alpha$ 強行拉高至 `0.7`（LCC 佔比 70%），給予排序梯度絕對的主導權。

### 2. 權重排除分層學習率 (Layer-wise LR with Proper Weight Decay)

為了保護 ImageNet 預訓練得到的低階視覺特徵，同時給予高階美學分類器足夠的學習動能，系統實作了**分層參數派發群組**：

* **特徵提取層（Features）**：給予 $0.1 \times LR$ 的微弱學習率，進行保守微調。
* **分類回歸層（Classifier）**：給予 $1.0 \times LR$ 的標準學習率，全速學習美學排序。
* **L2正則化精準打擊**：在進行 `weight_decay` 懲罰時，程式碼會動態過濾參數，**嚴格將所有一維張量（BatchNorm 的 $\gamma、\beta$ 以及卷積與線性層的 Bias）從權重衰減中排除**。這能有效防止 BatchNorm 的統計分佈被 L2 強行扭曲，確保模型收斂的底氣。

### 3. 以相對排序（Val SRCC）為信仰的餘弦早停機制

* **動能重置（餘弦退火）**：優化器外掛 `CosineAnnealingWarmRestarts` 策略（$T_0=5, T_{mult}=2$），讓學習率呈現週期性的折線下潛與猛烈重置（猛踩油門），藉此強制震盪出局部死水。
* **評估指標切換**：早停機制（Early Stopping）徹底切斷與 Val Loss 的綁定。系統改以 **Val SRCC（斯皮爾曼等級相關係數）** 作為儲存模型與判定進步的唯一標準。只要模型的「挑圖相對排序能力」還在創新高，即使 Val Loss 因為 Huber 的物理底噪發生躺平或反彈，訓練也會堅定地執行下去，直到觸發 `early_patience` 的次數極限。
